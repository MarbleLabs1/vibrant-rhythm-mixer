# vibrant-rhythm-mixer

## Getting started

Requires Node.js & npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
# Clone the repository
git clone https://github.com/MarbleLabs1/vibrant-rhythm-mixer.git
cd vibrant-rhythm-mixer

# Install dependencies
npm i

# Start the development server
npm run dev
```

## Tech stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Deployment

Build with `npm run build` and deploy the `dist` folder to your host of choice.
